# 小海关 · 可控代理插件

> 基于 Mihomo(clash 内核)的可控代理:勾选哪台终端走代理、哪台直连。
> 交互原型见 原型设计/小海关交互原型.html

> **平台口径(2.x 起)**:本 2.x 版本线仅限 **UFI-TOOLS-ZWRT(1.0.0)** 面板(依据 `docs/(1.0.0)插件开发文档.md` 适配);安装/更新由插件商店『先移除旧版再写入』处理,手工更新同口径(文档 §8)。

- **修复按钮无效果根修(2026-09-02)**:fwClean 函数定义在早期重构中被误删而调用保留——引擎启停路径不经过它(直接执行脚本)所以一直未暴露,坏的只有「一键修复(规则残留)/自愈/停止并还原」三条路径;且 doRepair 无异常兜底,失败静默(无提示无复诊无日志)。修复=恢复 fwClean 定义(先写最新 fw.sh 再执行 clean 并回读校验)+修复循环逐项 try-catch(失败 toast+操作日志留痕)
- **本机代理限时自动关闭(面板优先)**:默认「⏱ 5 分钟」——开启本机代理后设备侧 shell 计时(关页面也生效),到点自动摘除 OUTPUT 接管恢复面板直连出站,面板状态下次打开自动对账;可选 15/60 分钟;「一直开启 ⚠」带面板耦合警告(面板出站将走引擎,引擎异常波及面板)。总览页本机代理行的徽标按钮切换策略
- **日志诊断(运行态+停止态)**:运行态——日志开且 debug 级→警告(输出量巨大曾单日 6MB);开且 ≥200KB→警告建议清理(一键清空);≥256KB→严重警告(自动清理已触发线);停止态——运行日志残留即警告(一键清理)
- **面板优先原则(用户定调)**:小海关尽可能不影响 UFI 面板——访问面板流量/面板自身 DNS/TUN 路由均已天然隔离;真实耦合是资源与「本机代理」:诊断新增系统可用内存预警(<100MB 提示开低内存模式保面板),本机代理开启会让面板出站耦合进引擎,面板优先场景建议保持关闭
