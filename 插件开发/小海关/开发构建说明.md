## 源码与发行文件

`插件.js` 是 ES 模块入口，不能直接粘贴到面板。面板安装文件仍为 `上架插件/小海关插件.txt`，使用标准 `<script>...</script>` 包裹，不需要额外 JS 文件或设备侧构建工具。

| 文件 | 职责 |
|---|---|
| `插件.js` | 配置与运行状态、操作锁、界面、分流生成及生命周期编排 |
| `src/工具.js` | 转义、编码、地址检查、线路命名与默认选择 |
| `src/面板接口.js` | 同源 Shell 请求与文件上传 |
| `src/订阅解析.js` | 现有订阅块提取与首个选择组识别 |
| `src/状态采集.js` | IPv6 邻居命令、UDP 回流证据判定 |
| `src/启动脚本.js` | 从配置和固定路径参数生成启动脚本 |
| `构建.mjs` | 合并、压缩和产物检查 |
| `构建发行版.sh` | 检查构建依赖，调用构建程序 |

模块不导入入口，不独立执行初始化，不自行修改入口中的配置、运行状态或锁。启动脚本生成函数显式接收所需配置和路径。模块迁移保持原业务实现，订阅解析和启动流程的既有缺陷需要独立修复及验证。

## 安装开发依赖

在 `插件开发/小海关/` 目录执行：

```sh
npm ci --ignore-scripts
```

依赖版本由 `package.json` 和 `package-lock.json` 固定：esbuild 负责模块合并，Terser 负责压缩，Acorn 负责语法与结构检查。`node_modules/` 和 `.build/` 不入库。

## 检查构建

从项目根目录执行：

```sh
sh 插件开发/小海关/构建发行版.sh --check
npm test --prefix 插件开发/小海关
```

`--check` 生成：

- `插件开发/小海关/.build/插件.js`：可读的单文件脚本，用于调试及旧浏览器测试入口。
- `插件开发/小海关/.build/小海关插件.txt`：与正式构建格式相同的本地核验产物。

检查模式不覆盖 `上架插件/`。模块合并使用浏览器 IIFE、ES2020 目标，不生成模块分片或外部运行时依赖。保留重复加载守卫；不混淆对象属性名。构建遇到警告、语法错误、禁止标记或额外产物时中止。

## 正式发行

确认所有功能验收完成后，同步入口版本号、`CHANGELOG.md` 和 `使用说明.md`，再执行：

```sh
sh 插件开发/小海关/构建发行版.sh
```

只分发 `上架插件/小海关插件.txt`，禁止手改。SHA-256 只在终端输出。本次结构调整没有发布新版本或更新设备上的插件。

真机只读回归通过 Ego 已登录页面运行，任务空间编号使用当前实际编号，不写入登录凭据：

```js
const { runRegression } = await import('file:///实际项目绝对路径/插件开发/小海关/harness/运行状态采集回归.mjs');
await runRegression(taskSpace, 实际任务空间编号);
```

第三个参数为 `true` 时，会通过设备现有混合端口进行一次有证书校验、限时且小流量的 HTTPS 请求，以获得真实连接样本。默认不产生该请求。脚本只执行提取出的采集命令及字段表达式，不加载完整插件，不调用具有重载或防火墙副作用的 `collectStatus()`。

验证结果仅覆盖生成与采集：没有 UDP 样本时不能声称 UDP 转发通过；不代表白名单透明转发、游戏业务、长期稳定性或性能目标完成。旧 harness 的面板 stub 测试不作为真实网络验收证据。
